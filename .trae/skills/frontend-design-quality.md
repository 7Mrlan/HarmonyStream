# 前端设计质量准则（Claudio 项目）

## 触发场景
- 新页面布局阶段
- 组件视觉走查
- 用户反馈"看着不高级 / 不舒服 / 没风格"

## Claudio 视觉目标
**关键词**：暗黑底 · 像素字体 · 荧光高亮 · 留白克制 · 信息层级清晰

参考效果图（图二）的关键元素：
- 顶部大号像素时钟（21:11）— 主视觉锚点
- ON AIR 荧光绿小圆点 — 点睛色
- 当前曲信息行（标题 + 状态）— 次级层级
- 对话气泡（DJ 文案）— 长文区，留呼吸
- 输入框 + 麦克风按钮 — 交互区低调

## 设计七条铁律

### 1. 网格优先
- 间距用 4 的倍数：`p-1`(4) / `p-2`(8) / `p-3`(12) / `p-4`(16) / `p-6`(24) / `p-8`(32)
- 禁用 `p-5` `p-7` 这类奇数倍

### 2. 字号阶梯（只用 4 档，多了乱）
- `text-xs` (12)：辅助标签
- `text-base` (16)：正文
- `text-2xl` (24)：区域标题
- `text-7xl` (72)：英雄数字（时钟）

### 3. 颜色层级（只用 token，禁裸值）
- 背景：`bg-bg`（绝对黑）
- 卡片/面板：`bg-panel`（近黑，不用纯灰）
- 主文字：`text-text` （米白，不用 #fff）
- 次文字：`text-muted`
- 点睛：`text-accent`（仅用于状态指示和激活态，全屏不超过 3 处）

### 4. 对比度
- 重要内容必须 ≥ AA（4.5:1）
- 像素字体在小字号下要加 `tracking-pixel` 字距，否则糊

### 5. 留白
- 屏幕边缘左右至少 `px-4`(16)
- 文字段落之间 `gap-3`(12) 起步
- 大区块之间 `gap-8`(32)，用空气分割胜过用线

### 6. 动效克制
- 状态切换 ≤ 200ms
- 像素风不做 ease-spring，统一 `ease-out` 直接到位
- 唯一允许"软"动效：ON AIR 圆点的呼吸（1s 循环 opacity 0.4 → 1）

### 7. 边框与圆角
- 像素风用 1px 硬边框（`border border-line`）
- 圆角用 `rounded-md`(6) 或 `rounded-none`，禁 `rounded-full` 大块面
- 头像圆角：`rounded-md` 而非 `rounded-full`，强化像素方块感

## 自检清单（提交前过一遍）
- [ ] 是否用了 token 之外的颜色？
- [ ] 字号是不是只在那 4 档里？
- [ ] 间距是不是 4 的倍数？
- [ ] 同屏有没有超过 3 个荧光绿点？
- [ ] 暗背景下文字对比度够不够？
- [ ] 像素字有没有 `tracking-pixel`？
- [ ] 所有交互按钮有没有 `Haptics`？
