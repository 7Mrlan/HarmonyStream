# UI 自评指南（Claudio 项目）

## 何时使用
- 自己刚做完一屏，想客观评价
- 用户说"感觉不对但说不上来"
- 迭代到瓶颈，需要外部视角

## 评审三视角

### 视角一：5 秒首屏测试
让"假想用户"打开页面 5 秒，回答：
1. 这是干嘛的？
2. 我现在该点什么？
3. 它在做什么（播放中？等待中？）？

任何一题答不上来 = 信息层级有问题。

### 视角二：盲点扫描
逐项问：
- 这屏唯一的主角是谁？（必须能一句话答出）
- 删掉哪些元素后核心功能不受影响？（删之）
- 哪两个元素抢戏？（弱化其一）
- 留白够吗？（不够，再加）
- 有没有"为了填空间而存在"的元素？

### 视角三：边界压测
- 最长歌名怎么显示？
- 没有封面图怎么办？
- 网断了什么样？
- 极小屏什么样？
- 老人手大手指点不准会怎样？

## Claudio 项目专用打分表（每项 1-5 分）

| 维度 | 不及格 (1) | 及格 (3) | 优秀 (5) |
|---|---|---|---|
| **视觉风格统一** | 混风格 | 像素风但偶有杂色 | 全屏一致赛博质感 |
| **信息层级** | 主次不分 | 能找到主角 | 视线动线流畅 |
| **像素字应用** | 全屏宋体 | 标题用了 | 字体+字距+大小都到位 |
| **点睛色克制** | 满屏荧光 | 用了 3-5 处 | 只在关键状态出现 |
| **暗色舒适度** | 纯黑刺眼 | OK | 黑得有层次 |
| **触感反馈** | 无 | 主按钮有 | 主+次+错误三档 |
| **加载/空/错三态** | 缺 | 有但简陋 | 三态各有像素风插画 |
| **微动效** | 全无 | 有但平庸 | 呼吸/扫描线/打字机 |

低于 3 分的维度立刻打回去重做，不上线。

## 常见病灶

### 病灶 1：信息过载
症状：一屏塞 7 个以上信息块
解药：拆 2 屏 / 折叠次要项 / 删掉非核心

### 病灶 2：风格漂移
症状：一半像素风一半 Material
解药：定 token + 强约束，禁止裸值

### 病灶 3：暗色空洞
症状：纯黑 + 白字，像废弃命令行
解药：加点阵背景 + 微弱扫描线 + 一处荧光绿

### 病灶 4：交互冷淡
症状：点了没反应
解药：active 态 + Haptics + 200ms 过渡

### 病灶 5：英文/中文混排丑
症状：像素英文 + 默认中文，气质不统一
解药：中文用 VT323 拉丁形态 + 系统中文回退，或专门找像素中文字体

## 输出格式
当被要求做 UI 评审，按以下结构产出：
1. **整体印象**（1 句话）
2. **打分**（按上表，每项给分）
3. **三个最严重问题**（按优先级）
4. **三个具体修改建议**（要给到代码级）
5. **保留什么**（不要全盘否定，肯定好的部分）
